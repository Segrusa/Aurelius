**Vraag:** per employee guidelines kunnen definiëren, vooral coding guidelines.
**Verschil met instructies:** instructies beschrijven de rol van één employee (wie ben je, wat doe je). Guidelines zijn werkregels (hoe schrijf je Rust, hoe werk je met worktrees), en die gelden vaak voor meerdere employees.

**Scope:** een bibliotheek op company-niveau. Elke guideline heeft een titel, markdown en versies (append-only), en is te archiveren en terug te zetten. Je koppelt een guideline aan employees en/of projecten. Een run krijgt de guidelines van zijn employee plus die van zijn project, als een gelabeld blok in de systeemtekst, direct na de identiteit en de instructies. Een run houdt de versies vast die hij kreeg (snapshot per run, zichtbaar in de trace). Agents stellen voor met `propose_guideline`, een board member beslist met een diff in de inbox. Bewerken kan op desktop en mobiel. Er is een eenmalige startset.
**Buiten scope:** een combinatie employee × project, koppelen aan een department, versies van koppelingen, definitief verwijderen, guidelines voor Claude-subagents afdwingen (alleen een regel in de kop, zie B3).
**Protocol:** **additief binnen protocol 5** (feature `guidelines`, `guideline.*`-reads/writes/events, een eigen tabel `guideline_proposals`). Er komt geen nieuwe major (impactanalyse §2, §7).
**Schatting:** ≈ **15,5 dagen** werk, doorlooptijd ≈ 1,5 week (Forge 4, Flux 3, Bridge 2,5, Schema 1,5, Pulse 1,5, Nexus 1, Trace 1, Sentinel 0,5, Titan 0,5).
**Afhankelijkheden:** **de bouw (AUR-GL-01) start pas na de merge van AUR-MU-04.** Fase 4 raakt ook `agent-bridge/src/mcp.rs`, `protocol/*`, `storage/src/{lib,migrate}.rs`, `daemon/src/api/*` en de clients (impactanalyse R8). Guidelines gebruiken ook B10 van Fase 4: een tekst met een vault-secret wordt geweigerd.
**Bouwvolgorde:** Schema 0023 + storage ‖ Forge domain → protocol bevriezen + gen-dart → Flux, Bridge ‖ Nexus `propose_guideline` → Forge contextblok, sessiecheck en snapshot (bestanden die Fase 4 niet raakt) → Pulse E2E, Trace, Sentinel.
**Risico's:** prompt-injectie via een guideline (alleen board members, de kop zegt dat guidelines geen rechten geven, de rechten zitten in de daemon). Een te groot blok laat runs falen (`ContextTooLarge`), daarom de limiet van B4. Veel wijzigingen geven veel nieuwe sessies (alleen voor de getroffen gesprekken, en de UI zegt hoeveel). Subagents van Claude Code krijgen het blok niet (Nova OV-09).
