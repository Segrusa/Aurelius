Rust style

  • Edition 2024; the toolchain is pinned in rust-toolchain.toml.
  • Format with rustfmt. Clippy gets no new warnings in the code you touched.
  • Run cargo clippy -p <crate> before you commit, not after review.
  • Limits and fixed values are named consts next to their type.
  • Errors are thiserror types. No unwrap outside tests.
  • Every pub item gets a /// doc comment.
