Build notes

PartRule
TabsActivity (default) and Timeline replace the single Activity feed. The Activity tab shows a count of open questions for you. Keyboard: arrow keys move between tabs (ARIA tablist).
PlanThe top of the Activity tab is the ticket's plan: the main task's todo list (today PlanPanel/MainPlan at the top of the properties panel, which leaves that panel). One row per step, with the plan's status line above it. The employee and state of a delegated step are on the cards below, not repeated in the plan. The current step shows its plain-language “now” line. No todo list yet: “Orion is making the plan…”; a ticket without a main task has no plan block.
Properties panelKeeps only Properties and Files. Its Activity tab goes: that history is the Timeline tab.
Which cardsOne card per delegated task on this ticket; the main task is the Plan above. Working now = running, waiting or asking. Done = finished tasks, as one compact row each. A failed or stopped task gets a card with state “Stopped” and its error in plain words.
Card orderAsking you first (full width, amber), then working, then waiting; ties by last activity.
State chipNeeds your answer (open question or approval to you) · Working (run active) · Waiting for X (task waiting on a delegation or a person) · Stopped · Done.
Status lineOne segment per plan step of the employee: done green, current light green, asking amber, open grey. Below it “Step n of m” and time on the task. No plan yet: one indeterminate segment and “Getting started”.
NowThe employee's latest own text in its run, cut to 2 lines. While a tool runs without new text, a fixed phrase from the tool (“Running the tests…”, “Changing the export code…”); lookups (read, grep, ls, git status) are never named. “· 20 s ago” when older than 10 s.
StepsThe plan steps with their time. A card shows at most 5; more becomes “+3 earlier steps”.
QuestionsAn open question or approval for a board member sits inside the card of the employee who asks it, with its options as buttons (the employee's own pick labelled) and a free-text reply. Answering uses the existing answer path; the card goes back to Working. Questions to another employee are not shown here, only in Timeline.
Done ticketAll cards become “Who did what”: one summary sentence per employee (the task's result, first sentence), the full status line and the result labels.
TimelineThe current feed with the plain-language work blocks from v1, but newest first. The composer moves to the top. New items while scrolled down show “↑ n new” instead of jumping. Filters: All / Changes / Messages plus one chip per employee; “Timeline of X →” on a card opens this tab with that chip on.
AccessibilityThe overall line is a status region; a new question is announced once. Colour is never the only signal: state chips have text, segments have “Step n of m”. Pulse is off with reduced motion.
Narrow (< 760 px)One card per row; the question goes under the steps.
